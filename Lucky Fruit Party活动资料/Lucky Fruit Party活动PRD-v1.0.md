## 1. 需求概述

### 1.1 活动定位

Lucky Fruit Party 是围绕 Lucky Fruit 游戏设计的积分累计与周榜竞争活动。用户通过 Lucky Fruit 游戏获取 gold coin，活动页将 gold coin 转换为活动 point，并以 Daily Task 和 Weekly Ranking 两个页签承接奖励与排名。

### 1.2 活动时间

| 配置项 | 页面显示 |
|---|---|
| 活动时区 | GMT+2 |
| 开始时间 | Jul.1 00:00 |
| 结束时间 | Jul.31 23:59 |
| 倒计时 | 页面动态展示，随当前时间变化 |

### 1.3 产品目标

| 目标 | 说明 |
|---|---|
| 游戏导流 | 通过活动奖励引导用户进入 Lucky Fruit 游戏 |
| 行为激励 | 将游戏内 gold coin 转化为可追踪的活动 point |
| 长期参与 | 用 50K–5M 的累计目标形成持续参与路径 |
| 榜单竞争 | 通过周榜奖励激励高积分用户持续参与 |

## 2. 规则摘要

> 页面原文：`As long as you win 1 gold coin from the "Lucky Fruit" game, you will get 1 point`

### 2.1 积分规则

1. 用户进入 Lucky Fruit 游戏并获得 1 个 gold coin。
2. 活动积分增加 1 point。
3. 积分累计后推进 Daily Task 里程碑。
4. 周榜根据活动积分进行排名，页面展示 Top 1、Top 2、Top 3 奖励。

| 目标积分 | 奖励数量 | 页面图标描述 | 时效 | 页面状态 |
|---:|---:|---|---:|---|
| 50K | 1 | 猫咪主题装扮/头像框类图标 | x 1 day | Unachieved |
| 250K | 1 | 童趣人物主题装扮/头像框类图标 | x 1 day | Unachieved |
| 500K | 2 | 龙主题、果实主题图标 | 各 x 1 day | Unachieved |

| 5M | 3 | 科幻主题、果实主题、黄金载具主题图标 | 各 x 1 day | Unachieved |

### 3.2 Weekly Ranking 周榜奖励

页面展示前三名奖励。页面文字可直接确认数值奖励和时效，图标商品的正式名称仍需后台配置确认。

| 名次 | 数值奖励 | 图标奖励 | 时效 |
|---:|---|---:|---:|
| Top 1 | `+8000`；`+50000 EXP ×3` | 3 个图标 | 各 x 7 days |
| Top 2 | `+6000`；`+50000 EXP ×2` | 3 个图标 | 各 x 5 days |
| Top 3 | `+3500`；`+50000 EXP ×1` | 3 个图标 | 各 x 3 days |

### 3.3 奖励口径待确认

| 待确认项 | 原因 |
|---|---|
| `+8000 / +6000 / +3500` 的货币类型 | 页面只展示数字与金币图标，需要确认是 gold coin、平台金币还是活动币 |
| `+50000 EXP` 的经验类型 | 页面展示 EXP 图标，需要确认对应用户经验、等级经验或其他成长值 |
| Daily Task 图标正式名称 | 活动页只展示图片，不展示商品名称 |
| `x 1 days` 的领取方式 | 需确认是自动发放、点击领取，还是达成后自动激活 |
| 周榜结算周期 | 页签名称为 Weekly Ranking，但页面未展示周起止时间和结算时刻 |

## 4. 客户端页面结构

### 4.1 页面结构总览

| 区域 | 内容 | 作用 |
|---|---|---|
| 顶部视觉区 | Lucky Fruit Party 标题、水果、老虎机、金币视觉 | 建立活动主题与识别度 |
| 活动时间区 | GMT+2 活动起止时间 | 告知活动有效期 |
| 倒计时区 | 天 / 小时 / 分钟 / 秒 | 强化时间紧迫感 |
| 页签区 | Daily Task / Weekly Ranking | 切换累计任务与周榜奖励 |
| 规则提示区 | 1 gold coin = 1 point | 解释积分获得方式 |
| 用户信息区 | 头像、用户名、当前活动积分 | 展示个人进度 |
| 奖励区 | 目标档位、奖励图标、状态按钮 | 展示可达成目标与领奖状态 |

### 4.2 Daily Task 页面

每个目标使用独立的舞台卡片展示，结构包括：

1. `Target: {积分目标}` 标题。
2. 奖励图标及有效期文案。
3. 状态按钮：当前页面为 `Unachieved`。
4. 多个目标纵向排列，用户通过上下滚动查看完整奖励路径。

### 4.3 Weekly Ranking 页面

周榜页结构包括：

1. 活动头图、活动时间、倒计时与页签。
2. `Top1 Reward`、`Top2 Reward`、`Top3 Reward` 三组奖励卡片。
3. 当前用户榜单占位信息，包括头像、用户名和积分。
4. 页面下方继续展示周榜用户/排名列表。

## 6. 状态与异常处理建议

| 场景 | 客户端建议 |
|---|---|
| 活动未开始 | 展示活动开始时间，不展示可领取奖励 |
| 活动进行中 | 正常展示积分、目标、奖励和周榜 |
| 活动已结束 | 展示结束态；保留历史结果或按运营配置隐藏入口 |
| 积分刷新中 | 展示 loading，避免使用旧积分覆盖新结果 |
| 奖励发放中 | 展示“发放中/稍后到账”，避免重复点击 |
| 奖励发放失败 | 展示失败状态，并提供重试或联系客服入口 |
| 网络异常 | 保留最近一次成功数据，同时提示刷新 |
| 周榜未加载 | 保留榜单骨架，不将空数据误显示为 0 分 |

## 7. 验收标准

### 7.1 活动基础信息

- [ ] 活动名称与页面视觉一致，为 `Lucky Fruit Party`。
- [ ] 活动时间按照 GMT+2 展示为 Jul.1 00:00 – Jul.31 23:59。
- [ ] 倒计时可根据服务端时间实时变化。
- [ ] 活动结束后不再累计新的活动积分。

### 7.2 积分与任务

- [ ] Lucky Fruit 每获得 1 个 gold coin，活动积分增加 1 point。
- [ ] Daily Task 按 50K、250K、500K、2.5M、5M 目标展示。
- [ ] 每档目标展示对应奖励图标、有效期和当前状态。
- [ ] 积分刷新后，个人进度与目标状态同步更新。

### 7.3 周榜与奖励

- [ ] Weekly Ranking 展示 Top 1、Top 2、Top 3 奖励。
- [ ] Top 1 / Top 2 / Top 3 数值奖励分别为 +8000 / +6000 / +3500。
- [ ] EXP 奖励分别为 +50000 ×3 / ×2 / ×1。
- [ ] 图标奖励时效分别为 7 天 / 5 天 / 3 天。

## 9. 待产品/运营确认项

1. gold coin、point、周榜数值奖励、EXP 分别对应什么资产或成长值。
2. Daily Task 是累计整场活动，还是按天/按周重置。
3. `x 1 days` 奖励的正式商品名称、领取方式和过期处理。
4. Weekly Ranking 的周周期、结算时刻、同分排序与发奖时间。
5. 用户是否可以重复获得同一图标奖励，或奖励仅首次达成发放。
6. 活动结束后未领取奖励是否自动发放、补发或失效。
7. 多语言文案、地区时区和服务端时间展示规范。
