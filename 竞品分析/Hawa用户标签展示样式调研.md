# Hawa 用户标签展示样式调研

> 调研时间：2026-07-24  
> 调研方式：在已授权 Android 真机上，通过 scrcpy 配套连接查看 Hawa。  
> 对照依据：[用户标签控件使用分析.md](/Users/xinyintiaodong/Downloads/用户标签控件使用分析.md)。

## 结论摘要

Hawa 不把身份信息收敛为一行紧凑、可组合的“基础标签条”。它将不同类型拆分到不同层级：

- **性别**是唯一在个人资料主信息区稳定出现的小型标签：蓝色圆形底，白色男性符号；当前样本未显示年龄。
- **VIP、财富、魅力**主要作为独立的等级体系、权益页或入场/昵称特效呈现，视觉强、占位大，常用金色描边、徽章和渐变名牌。
- **房间内的强运营标识**以动态入场横幅、礼物/活动特效、房间 ID 后的微型图标为主，信息密度高但会遮挡房间标题和麦位。
- 本次实际样本中没有出现国家、语言、年龄文本、常驻小型 VIP 徽章或并排的财富/魅力小标签；这只能说明**本次账号和所进入房间未触发**，不能据此判断 Hawa 没有对应能力。

## 按附件路径的实测记录

### 1. 我的页面与个人空间

个人页把 VIP 和等级做成明显的功能入口，而没有在昵称旁放置常驻小标签。顶部昵称区有可能被公会/活动入场横幅覆盖；这类横幅采用紫金色金属框、翼形装饰、头像、昵称和次数信息，视觉优先级远高于基础身份。

![我的页面](Hawa标签截图/01-我的页面.png)

进入个人空间后，昵称下方仅出现性别图标；简介、ID、统计数据、荣誉分类分区展示。此处没有显示国旗、语言、年龄、VIP 小徽章或财富/魅力条。

![个人空间](Hawa标签截图/03-个人信息页.png)

### 2. 用户资料卡

房间内点开用户后，底部抽屉式资料卡保留头像、昵称、性别、ID 与 `Medals` 入口。性别标签仍独立成行，不与 ID、等级拼接；勋章则通过入口下钻，避免在资料卡首屏堆叠。

![房间内用户资料卡](Hawa标签截图/08-房主用户资料卡.png)

### 3. 首页房间列表

首页房卡以房间封面、房名、简介、在线人数和游戏标识为主。例如 Carrom Pool 使用独立游戏胶囊图标。当前可见卡片未出现房主性别、国旗、语言、VIP 或财富/魅力等级。

![首页房间列表](Hawa标签截图/04-首页房间列表.png)

### 4. 语聊房内与公屏消息

房内的基础结构是 10 个圆形麦位；顶部显示一排小头像和人数。房间标题下的 ID 后出现 3 个连续微型装饰徽章。公屏里可见头像 + 昵称 + 行为文案（如 `enter the room`），但没有随消息行展示 VIP、财富或魅力小徽章。

高等级或活动触发时，动态横幅会横跨房间头部甚至麦位区域，包含大面积金属边框、角色头像、昵称、等级/次数和主题文案。它可以承担荣誉、活动或公会身份，但也明显影响信息可读性。

![房内主界面](Hawa标签截图/06-房间菜单.png)

![房内用户与动态特效](Hawa标签截图/09-房主资料卡.png)

### 5. VIP 体系

VIP 分为 VIP1–VIP6，采用横向 Tab。未开通的当前账号提示购买；页面用金色品牌字、棕黑渐变底、金色图标权益卡形成高级感。对比附件中“昵称前小徽章”的方案，Hawa 的 VIP 更像付费权益中心和可激活的展示资源。

![VIP 等级页](Hawa标签截图/10-VIP等级页.png)

### 6. 财富/魅力体系

Hawa 的 Wealth 与 Charm 是并列体系。Charm 页面展示 1–9、10–19……等级区间；每档有一个彩色徽章（带数字）和一个同色的长条昵称/说话特效。色彩随级别提升从青绿、粉、紫、橙红到多彩，辅以皇冠、宝石和花形装饰。

这与附件的“长条形财富/魅力等级标签”目标最接近，但 Hawa 在本次样本中把它定义为**可解锁的昵称特效资产**，而非聊天流或列表里的常驻轻量标签。

![魅力等级与昵称特效](Hawa标签截图/11-等级页.png)

## 可借鉴点与产品提示

1. **等级的资产化表达**：把等级徽章与昵称/说话气泡皮肤绑定，用户能直观看到升级后的可展示收益，适合用于财富和魅力成长体系。
2. **基础信息与荣誉信息分层**：Hawa 将性别留在首屏，将勋章放入 `Medals` 下钻，能避免用户资料卡横向拥挤；若需要更强的社交筛选，仍可在首屏补充国旗、语言等高价值信息。
3. **动态运营标签需设安全区**：Hawa 的入场横幅表现力强，但会短暂遮住房间标题与麦位。建议限制横幅高度、播放频率，并给房主信息和关键操作保留不被遮挡的区域。
4. **列表行宜保留轻量形态**：Hawa 本次房间列表和聊天行基本未展示等级小标签，整洁但降低了用户快速识别身份、语言和消费层级的效率。若复用附件方案，可在昵称后按“VIP → 性别年龄 → 国家/语言 → 财富/魅力”的优先级做可折叠展示。
