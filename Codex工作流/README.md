# Codex 工作流落地包

更新时间：2026-06-26

这个目录用于把重复的 Codex 协作方式沉淀成模板。目标不是多写文档，而是减少每次重新解释上下文、重新查漏、重新判断最新版本的成本。

## 使用顺序

1. 新任务先读根目录 [../PROJECT_INDEX.md](../PROJECT_INDEX.md)。
2. 再读对应模块的 `PROJECT_INDEX.md`。
3. 按任务类型选择模板：
   - PRD：读 [02-PRD评审版模板.md](02-PRD评审版模板.md)
   - HTML 原型：读 [03-HTML原型任务模板.md](03-HTML原型任务模板.md)
   - 多语言/弹窗：读 [04-多语言与弹窗文案模板.md](04-多语言与弹窗文案模板.md)
   - 评审查漏：读 [05-QA评审清单.md](05-QA评审清单.md)
   - 复杂任务：读 [06-子代理并行分工.md](06-子代理并行分工.md)
4. 产物命名按 [07-命名与版本收口规范.md](07-命名与版本收口规范.md)。
5. 需要长期复用上下文时，按 [08-agent-memory模板.md](08-agent-memory模板.md) 建一个 `agent-memory.md`。

## 最推荐的启动话术

```text
先读 PROJECT_INDEX.md、本模块 PROJECT_INDEX.md 和 Codex工作流/05-QA评审清单.md。
这次任务是【任务类型】。
请先判断当前版文件，必要时启动子代理做并行评审；不要误改历史版本。
完成后更新对应模块 PROJECT_INDEX.md 的当前版候选和待确认问题。
```
