## 使用建议

- 每次大改 PRD、HTML 原型或规则口径后，更新一次。
- 只写会影响下次任务判断的信息，不写流水账。
- 如果项目很复杂，优先让 Codex 读 `PROJECT_INDEX.md` 和 `agent-memory.md`，再读具体 PRD。
