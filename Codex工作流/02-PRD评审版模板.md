# PRD 评审版模板

适用于幸运礼物、游戏房、公会、风控、红包、活动等复杂产品需求。

## 生成前输入

```text
模块：
当前版文件：
参考文件：
目标读者：产品 / 研发 / 测试 / 运营 / 财务 / 风控 / 客服
上线策略：灰度 / 强更 / 配置开关 / 仅后台 / 待定
必须保留的旧口径或截图：
已知争议点：
```

## 推荐目录

1. 文档信息
2. 背景与目标
3. 当前结论与裁决摘要
4. 范围说明：本期做什么、不做什么
5. 用户/角色/权限
6. 核心流程
7. 页面与交互说明
8. 后台配置
9. 数据字段与状态机
10. 规则与计算口径
11. 异常与边界场景
12. 风控与合规
13. 多语言与客户端文案
14. 埋点与数据看板
15. 上线策略、开关、回滚
16. 测试验收清单
17. 待确认问题
18. 附录：历史版本/参考文档/截图

## 必须写清楚的评审点

- 当前默认口径是什么，历史口径是否废弃。
- 哪些规则可以后台配置，哪些必须发版。
- 异常状态如何恢复，失败是否补偿。
- 是否影响钱包、钻石、工资、返奖、提现或公会结算。
- 客户端旧版本如何处理。
- 操作日志、审计、客服解释路径是否完整。

## 子代理建议

- 产品评审代理：查流程、页面、角色和漏场景。
- 研发评审代理：查接口、状态、幂等、并发、回滚。
- 风控/财务代理：查成本、结算、套利、预算和合规。
- 文案代理：查弹窗、Toast、多语言和客服口径。
