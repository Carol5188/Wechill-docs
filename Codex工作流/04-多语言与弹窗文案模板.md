# 多语言与弹窗文案模板

适用于游戏房、风控、活动、充值、提现、红包等客户端提示和后台文案。

## 建议字段

| 场景 | key | 展示形式 | 触发条件 | 中文 | English | العربية | 按钮 | 备注 |
|---|---|---|---|---|---|---|---|---|
|  |  | Toast / Dialog / Banner / Empty / Confirm |  |  |  |  |  |  |

## 文案原则

- 不暴露具体风控因子。
- 不把业务限制伪装成网络错误。
- 金额、币种、时间、版本号必须可参数化。
- 客服可解释，研发可落 key，测试可复现触发条件。
- 阿语/RTL 场景要避免按钮顺序和数字混排出错。

## 必查场景

- 成功。
- 失败。
- 加载中。
- 超时。
- 余额不足。
- 权限不足。
- 版本过低/强更。
- 规则限制/风控限制。
- 二次确认。
- 不可撤销操作。
- 审核中/已驳回。

## 子代理建议

- 文案代理负责 tone、按钮、客服解释。
- 测试代理负责 key 和触发条件是否可测。
- 风控代理负责是否泄露规则。
