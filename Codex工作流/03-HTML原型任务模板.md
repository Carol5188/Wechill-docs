# HTML 原型任务模板

适用于后台、客户端交互、活动页、字段说明页面。

## 生成前输入

```text
模块：
目标页面：
参考原型/截图：
必须匹配的旧样式：
必须新增的交互：
需要展示的数据字段：
是否需要移动端适配：是 / 否
是否需要本地浏览器 QA：是 / 否
```

## 后台原型必备

- 顶部标题与版本说明。
- 筛选区：对象定位、类型、状态、时间、风险/业务维度。
- 主表格：关键字段、状态、金额/数量、操作列。
- 详情/弹窗：操作前确认、影响范围、备注、审计。
- 空状态、加载状态、禁用状态、错误提示。
- 操作日志或审批记录。

## 客户端原型必备

- 入口位置。
- 首次弹窗和二次确认。
- 成功、失败、超时、余额不足、网络异常、版本过低。
- RTL/阿语展示风险。
- 关闭、返回、最小化、断线恢复。

## QA 要求

- HTML/CSS/JS 无明显语法错误。
- 关键按钮能打开对应弹窗或切换页面。
- 表格在移动端不撑破页面，必要时表格内部横向滚动。
- 不用“说明文字”替代真实控件。
- 如果有图片资源，确认引用路径存在。

## 交付时必须说明

- 文件路径。
- 新增了哪些页面/弹窗/状态。
- 已做哪些验证。
- 还有哪些待接入真实接口或待确认字段。
